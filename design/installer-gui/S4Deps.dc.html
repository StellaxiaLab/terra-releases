WireGuardwireguard-tools없음관리자 권한 필요
sudo apt-get install -y wireguard-tools
건너뛰면 노드 사이 WireGuard 연결이 꺼져요.

Dockerdocker.io없음관리자 권한 필요
sudo apt-get install -y docker.io
건너뛰면 fleet-host를 쓸 수 없어요. Master가 이 노드에 놓은 컨테이너 좌석을 돌리지 못합니다.
